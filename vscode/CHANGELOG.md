# Changelog

## 0.2.0

- The background is lighter and greyer (`#23272e`, was `#0f1218`), closer to One Dark Pro. The cursor line, selection, comments, line numbers and punctuation are lifted to match.
- Rime and Rime Glacier swapped palettes. Rime is now the soft pastel set and Rime Glacier the crisper one. If you preferred the old Rime, pick Rime Glacier.

## 0.1.0

- First release with four variants: Rime, Rime Glacier, Rime Aurora and Rime Abyss.
