# Rime Theme

A cold theme in five variants: **Rime**, **Rime Glacier**, **Rime Aurora** and **Rime Abyss**, which are dark, and the light **Rime Frost**.

![Rime variants](https://raw.githubusercontent.com/w0x7y/Rime/main/assets/screenshot-all.png)

The dark four have cool gray backgrounds, lighter in Rime Glacier and darker in Rime Aurora and Rime Abyss. Rime Frost is frost white. All lean on blues, teals and violets. Keywords are split by kind: declarations are violet, loops yellow, conditionals bold rose, and returns and exceptions rose.

## Install

Search for **Rime Theme** in the Extensions view, or run:

```sh
code --install-extension w0x7y.rime-theme
```

VSCodium, Cursor and other editors that use Open VSX can install it from [open-vsx.org](https://open-vsx.org/extension/w0x7y/rime-theme).

Then run **Preferences: Color Theme** and pick a Rime variant.

## Install from source

```sh
git clone https://github.com/w0x7y/Rime
cd Rime/vscode
npx @vscode/vsce package
code --install-extension rime-theme-0.4.0.vsix
```

## Notes

- Semantic highlighting is on, so builtins like `Math`, `Error`, `Boolean` and `parseInt` get their color from the language server. Without a language server they fall back to the plain grammar colors.
- In TypeScript and JavaScript the grammar gives `return`, `await` and `yield` the same scope, so all three use the rose return color.
- The theme files and `package.json` are generated by the repository's `tools/build.py`: the colors from `palettes/`, which color each kind of code gets from the `SYNTAX` table in the script, and the version from its `VERSION`. Edit those, not the JSON.
