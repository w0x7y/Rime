# fzf

a shell script that adds rime's colors to `FZF_DEFAULT_OPTS`.

{{downloads}}

## install

```sh
mkdir -p ~/.config/fzf
curl -fsSL https://raw.githubusercontent.com/w0x7y/rime/main/general/fzf/{{slug}}.sh -o ~/.config/fzf/{{slug}}.sh
echo 'source ~/.config/fzf/{{slug}}.sh' >> ~/.bashrc  # or ~/.zshrc
```
