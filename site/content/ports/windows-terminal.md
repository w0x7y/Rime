# windows terminal

all five variants as color schemes, in one file.

{{downloads}}

## install

open **settings → open json file** and add the entries from `rime.json` to the `"schemes"` array. then pick the scheme under your profile's **appearance** settings, or set it for every profile:

```jsonc
"profiles": {
  "defaults": {
    "colorScheme": "{{name}}"
  }
}
```
