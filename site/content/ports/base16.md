# base16

the same 16 colors per variant, as scheme files in the [tinted-theming](https://github.com/tinted-theming/home) format. there's a base16 template for almost any software, so you can feed these to a builder such as [tinty](https://github.com/tinted-theming/tinty) and theme apps rime has no port for.
